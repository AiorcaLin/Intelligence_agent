# 04 - 订阅管理测试

> 所有接口均需 Bearer Token 鉴权

---

## 1. 订阅数据模型

```mermaid
erDiagram
    Subscription {
        UUID id PK
        UUID user_id FK
        UUID template_id FK "可选"
        String name "默认: AI情报"
        String domain "AI | Crypto | custom"
        String density_level "quick_scan | standard | research"
        JSON custom_keywords "可选"
        String frequency "daily | weekly | major_only"
        String push_time_bucket "00 | 03 | 06 | 09 | 12 | 15 | 18 | 21"
        Array formats "text | audio | video"
        Boolean is_active "默认 true"
    }
```

### 前端字段映射问题详表（BUG-007）

| 前端字段 | 后端字段 | 说明 |
|----------|----------|------|
| `density` | `density_level` | 字段名不同 |
| `"brief"` | `"quick_scan"` | 枚举值不同 |
| `"breaking"` | `"major_only"` | 枚举值不同 |
| `pushTime` ("09:00") | `push_time_bucket` ("09") | 字段名 + 格式不同 |
| `customKeywords` | `custom_keywords` | camelCase vs snake_case |
| `templateId` | `template_id` | camelCase vs snake_case |
