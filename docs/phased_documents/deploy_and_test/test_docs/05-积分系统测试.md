## 4. 关键审计点

> 以下是需要人工审查代码确认的要点

- [ ] **免费额度计算是否正确**：`abs(sum(free_daily records today))` 作为已用，与 50 取差值
- [ ] **消耗优先级**：是否真的先扣免费再扣付费
- [ ] **并发安全**：两个请求同时扣费是否会超额
- [ ] **充值 Mock 是否立即入账**：确认不依赖 callback
- [ ] **callback 是否重复入账**：Mock 已入账，callback 再调不应重复加
