## 1. 推送流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant API as Push API
    participant Svc as PushService
    participant DB as PushLog

    User->>API: POST /api/push/test {report_id, channels}
    API->>Svc: push_report(report_id, user_id, channels)
    loop 每个 channel
        Svc->>DB: 写入 PushLog (status=pending)
        Svc->>Svc: _send(channel, report, user)
        alt channel 已知
            Svc-->>DB: status=sent, sent_at=now
        else channel 未知
            Svc-->>DB: status=failed, error_msg
        end
    end
    API-->>User: {"ok": true, "message": "推送已发起"}
```

## 3. Celery 定时推送（`daily_push`）

```mermaid
flowchart TB
    A[Celery Beat 每小时触发] --> B[计算当前 3 小时桶<br/>如 09:00-11:59 → bucket=09]
    B --> C[查找匹配 bucket 的活跃订阅]
    C --> D{该订阅今日有报告?}
    D -->|有| E[调用 PushService.push_report]
    D -->|无| F[跳过]
    E --> G[channels = subscription.formats]
    G --> H["_send(text/audio/video)"]
    H --> I["❌ 不匹配 web/email/telegram"]
```
