## 3. 通用检查项（每个页面都要验证）

| # | 检查项 | 说明 |
|---|--------|------|
| A | 未登录访问 | 是否重定向到 /login |
| B | Token 过期 | 是否触发自动 refresh |
| C | Console 错误 | 打开 DevTools 记录所有 JS 错误 |
| D | Network 请求 | 记录所有 API 调用的 URL、状态码、响应体 |
| E | 移动端适配 | Chrome DevTools 切换手机视图 |
| F | 加载状态 | 是否有 loading 提示 |
| G | 空状态 | 无数据时是否有友好提示 |
