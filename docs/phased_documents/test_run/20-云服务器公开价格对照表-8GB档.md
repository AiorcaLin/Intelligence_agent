# 云服务器公开价格对照表（约 8 GB 内存 / 60 GB+ 盘 / 按量友好）

**日期**：2026-04-12  
**用途**：对照 `16-规格8GB厂商与地域推荐.md` 中的几类选项，从**官网/官方文档**摘录标价，便于你下单前比价。  
**说明**：

- 价格为 **厂商公开列出的套餐价或月费上限**，**不含**：税费、首购折扣、代金券、汇率、突发活动价。  
- **币种**：人民币 **元**、美元 **USD**、欧元 **EUR** 并列时，请以支付时汇率为准。  
- **按量**：表中 **小时价 × 当月使用小时** 通常有 **月费封顶**（与厂商规则一致）；DigitalOcean 自 **2026-01-01** 起 Droplet 为 **按秒计费**（最低约 60 秒）。**参考**：[DigitalOcean Droplet Pricing](https://www.digitalocean.com/pricing/droplets)  
- **加密货币**：Vultr 等可能通过 **BitPay** 等接入（以结账页为准）。**参考线索**：[BitPay — Vultr](https://www.bitpay.com/directory/vultr)
