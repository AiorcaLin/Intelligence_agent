## 2. J1 — 创始人自用：情报生成与审阅（Phase 1）

## 3. J2 — 社交媒体推广流程（Phase 2）

```mermaid
flowchart TD
    A["情报已通过 J1 审阅"] --> B["多模态转换"]
    B --> B1["文字版\n各平台格式适配"]
    B --> B2["音频版\nEdge-TTS"]
    B --> B3["视频版\nMoneyPrinterTurbo"]
    
    B1 & B2 & B3 --> C["Agent 自动多渠道分发"]
    C --> C1["Twitter\n推文串 + 平台链接"]
    C --> C2["Telegram 频道\n免费摘要 + 平台链接"]
    C --> C3["知乎/公众号\n图文 + 平台链接"]
    
    C1 & C2 & C3 --> D["路人看到内容"]
    D --> D1{"感兴趣?"}
    D1 -->|"是"| E["关注账号\n开始每日阅读"]
    D1 -->|"否"| F["流失"]
    
    E --> G["持续阅读免费摘要"]
    G --> H{"想要更多\n个性化定制?"}
    H -->|"是"| I["点击平台链接\n注册 SaaS"]
    H -->|"否"| J["继续阅读免费摘要\n成为口碑传播者"]
```

**关键设计**：社交媒体不设付费订阅，所有内容免费展示，末尾附平台引流链接。

## 4. J3 — 新用户注册→创建订阅→首次推送（Phase 3）

```mermaid
flowchart TD
    A["用户来源：社交媒体引流\n/ 口碑 / 搜索"] --> B["落地页\n30秒了解产品价值\nCTA: 免费体验"]
    B --> C["注册\n邮箱 + 密码\n行业（可选）\n公司（可选）"]
    C --> D["发放每日免费积分（50）"]
    D --> E["引导创建第一条订阅"]
    
    E --> F["订阅配置（单页完成）"]
    F --> F1["选择领域\nAI / Crypto / 自定义"]
    F1 --> F2["选择信息密度\n速览 / 标准✓ / 研究级"]
    F2 --> F3["选择配方\n浏览共创中心 / 默认推荐✓\n每个可免费试一次"]
    F3 --> F4["选择推送设置\n频率: 每日✓ / 每周\n时间桶: 09:00✓\n格式: 文字✓ / 音频 / 视频"]
    
    F4 --> G["创建订阅完成"]
    G --> H["立即生成第一份情报（免费）"]
    H --> I["情报中心展示结果\n你的第一份AI情报已生成！"]
    I --> J["引导：\n查看情报 / 创建更多订阅 / 充值"]
```

**关键设计**：
- Onboarding 必须 < 2分钟完成
- 所有配置在一个页面/流程中完成
- 首份情报免费且立即生成，让用户看到即时价值

## 9. J8 — 用户生命周期状态机

```mermaid
stateDiagram-v2
    [*] --> Anonymous : 社交媒体看到内容

    Anonymous --> NewUser : 注册
    NewUser --> ActiveFree : 完成Onboarding\n创建首条订阅

    ActiveFree --> ActivePaid : 充值积分
    ActiveFree --> Dormant : 7天未登录

    ActivePaid --> ActivePaid : 持续使用+续充
    ActivePaid --> LapsedPaid : 积分耗尽\n且30天未续充

    Dormant --> ActiveFree : 推送唤回\n或促销活动
    Dormant --> Churned : 30天无响应

    LapsedPaid --> ActivePaid : 续充积分
    LapsedPaid --> Churned : 60天无活动

    Churned --> ActiveFree : 重新激活

    note right of ActiveFree
        每日免费积分保证
        即使不付费也有价值
    end note

    note right of ActivePaid
        核心变现用户
        关注留存和ARPU
    end note
```

**关键转化漏斗**：

| 转化节点 | 目标转化率 | 关键动作 |
|:---------|:----------|:---------|
| Anonymous → NewUser | 3-5% | 落地页优化 + 社交媒体引流 |
| NewUser → ActiveFree | 80%+ | Onboarding < 2分钟 + 即时首份情报 |
| ActiveFree → ActivePaid | 5-10% | 免费额度用完后的转化引导 |
| ActivePaid 月留存 | >80% | 每日推送触达 + 历史价值积累 + 重要性反馈闭环 |
| ActivePaid → LapsedPaid | <20% | 积分余额提醒 + 续充优惠 |
